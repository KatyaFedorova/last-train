LAST TRAIN

Four passengers. One Agent, one Awake ally, two Sleepers. Find the Agent.

  • Awake always tells the truth.
  • Agent always lies.
  • Sleeper is honest but blind: answers as if everyone were a Sleeper. A Sleeper always says nobody is an Agent or Awake, and that any two people are the same kind.

You have 3 yes/no questions, then accuse.

ask B Is D an Agent?
ask C Are A and B the same kind?
accuse A            accuse A ally D
help                new

Name passengers by seat (A–D) or by name. Score: 100 for the Agent + 50 for the ally + 25 per unused question.
