# Nova Bank (UI mock)

A single-file mobile banking home screen: balance, swipeable card carousel,
quick actions, recent operations and a bottom tab bar. Demo data only.

Open `bank-app/index.html` in a browser (use phone size in dev tools), or
serve it: `python3 -m http.server -d bank-app 8000`.

Edit the `cards`, `balances` and `operations` arrays at the bottom of
`index.html` to change what it shows.
